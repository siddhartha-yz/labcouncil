# DeepSeek Flash 最小工作流预注册

日期：2026-10-04（Asia/Shanghai）。开始付费请求前固定本协议。

本实验为 LabCouncil 自有验证脚本，不运行 Virtual Lab 或 freephdlabor 的完整系统，也不复现其论文结果。Executor 和 Reviewer 是顺序调用的两个真实模型角色，使用同一 DeepSeek Flash；角色区分不代表模型之间独立。

## 任务与干预

第一轮：seed=7，训练 40 / 测试 100 个合成样本，真实关系 `y=2+3x+noise`，x 均匀分布于 [-2,2]，噪声标准差 0.4。仅比较普通最小二乘线性回归与训练目标均值基线的测试 MSE，测试标签不添加异常值。模型必须调用本地工具，提交结构化、引用实验 ID 的数值报告。

Reviewer 必须调用本地验证工具，从落盘 CSV 重新计算预测、基线和指标，报告验证结论与局限。

第一轮结束后保存状态并退出进程。第二次启动读取状态，将下列**预先写好的测试评审意见**作为新 user 消息加入 Executor 历史：

> 单次、干净数据的结果不足以评估稳健性。将任务版本更新为 2，使用 seeds 7、19、31；每个测试集的 10% 标签添加幅度为 10 的正负异常值，训练数据保持不变；补报 MSE、MAE 和 median absolute error。生成新实验证据，保留上一轮结果，不将此检查推广为真实研究质量结论。

这不是用户实际参加组会后的意见，也不是模型 Reviewer 自动获得人类决策权。它仅作为受控输入验证指令影响，记录 `decision_source=prewritten_test_fixture`、`human_confirmed=false`。

## 预先规定的通过标准

1. 两轮 Executor 均产生真实 API 工具调用，参数严格匹配对应任务版本的 seeds、异常值比例和指标，禁止额外字段、任意代码、文件路径或网络工具。
2. 工具实际执行、保存 CSV 与实验 JSON；产物带 SHA256。后续产物不覆盖第一轮。
3. 两轮 Executor 的 JSON 报告覆盖对应的全部 seed/metric，数值与原始工具结果一致（绝对或相对误差不超过 1e-4），证据引用准确，包含非空局限说明。
4. 两轮 Reviewer 均调用验证工具，重算预测和指标、检查哈希；其 JSON 验证结论与工具实际结果一致。
5. 第二轮由全新 Python 进程恢复第一轮状态与历史；新工具调用体现预设修改。只验证组会边界恢复，不宣称任意执行中崩溃恢复。
6. 再次执行已完成的第二轮命令应直接返回，新增 API 调用数和工具执行数均为 0。

## 预算与停止条件

- 固定 `deepseek-flash`；关闭 thinking，temperature=0，每次输出上限 2048 token。
- Executor/Reviewer 每个阶段最多 3 次 API 请求，全实验最多 12 次；单次超时 45 秒，无自动重试或模型回退。
- 每个阶段最多 2 次工具调用；拒绝非法参数、重复 seed、未知证据 ID 和超预算调用。
- API、报告格式、工具执行或验收失败，保存已发生的响应与错误并停止。不为通过验收静默改写报告。
- 记录调用次数、token、耗时和全部失败。未查询账户余额，费用不由 token 数直接当作已结算数值。

## 范围限制

只检查受控工具、数值报告、验证角色、固定评审输入和阶段边界恢复。未验证文献搜索、自由编程、GPU 实验、真正交互式人类会议、定时运行、长周期工作、科学创新或多 agent 优势。真实任务和重复对照实验仍需后续开展。
