# 菜鸟使用测评 v1：先固定输入和评分，再运行

冻结基线：`60e0dcfc146205ac4b868af8e305d29c879f07d6`。数据哈希见 manifest.json。

## 到底测什么

48 个合成场景：40 个多轮对话与状态场景、8 个实际浏览器旅程。用户不会五项输入表、权限口令、后台任务/请求单位、证据 ID 或版本号。文本来自预先写好的不同用户处境，不让被测模型生成迎合自己的用户输入。可见按钮选项是用户能读到的中文；点击工具卡产生的内部命令不冒充用户懂后台。

覆盖模糊目标、碎片表达、资源和时长、拒绝付费、口语授权/撤回、只讨论、暂停/恢复/取消、条件继承、失败与未知、夸大成果、资料注入、断线、旧卡片、重启，以及一轮与两轮实际工作。

不把“菜鸟”仅替换成错别字。不要求用户知道 OLS、seed、operation_ref 等术语。初始条件不完整时，做好澄清和说明当前能力也能通过；科学任务做不到时，诚实说明并给可行下一步，而不是伪造结果。

## 分层与分母

1. 40 个对话/状态场景通过真实本机 HTTP 接口提交。32 个不调用成功模型桩：冷启动用当前真实平台的本机回执；控制路径用固定模拟环境，只测控制，不计为模型理解力。测试保护会阻止这些场景意外进入真实模型，记为模型调用尝试，不把被保护挡住当作平台本来就不会调用。
2. 8 个标为 live 的场景使用当前 Codex CLI `gpt-6.1-sol / high`，其中包含实际后台一步和两轮工作。模型启动整个运行最多28次；无自动补跑、切模型或删失败。每次仍受生产后台的超时和权限校验。公开查询总上限为0，不请求真实外部论文或运行上游代码。
3. 8 个浏览器场景走可见界面，记录输入、动作、状态、截图与数据库结果。不能用 HTTP 跑过来替代浏览器成绩。

预置已有数据、旧提案、失败报告、时间过期等是测试环境设置，不是用户发出的熟练指令。预置论文/网页片段是明确标记的合成夹具；不冒充读到了真实论文。五个点的旧计算用真实固定计算产生，不冒充科研成果。两条后台工作旅程另外调用生产研究执行器。

## 怎样评分

- **具体结果检查**：数据文件中的每项检查逐条运行，记录预期、实际、通过/失败/未测。保留失败分母；API异常也保留。
- **通用完整性检查**：初始输入保留、累计额度不暗增、历史消息/证据/快照不覆盖、未授权工具不执行、来源读取账本如实记录。检查实际数据库和工具结果，不信答复里自称完成。
- **答复可用性**：宿主按冻结的 good_response/minimum_help 查看整段真实答复，给通过/失败/未测和依据。看是否理解该用户的具体困惑，说明状态，给一个可操作的下一步；引用和专业缩写可按需保留，但不能只扔给用户口令或日志。
- **科研表述**：在8个 live 场景中核对引用、具体事实、验证边界、限制和后续建议；不能拿有效ID代替事实正确。
- **严格跑通率**：每个场景的具体结果、通用完整性和答复可用性都通过，才算跑通；浏览器旅程须全部必需观察通过。未测和失败都留在48的分母。也分别报告本机路径、真实模型、浏览器的分项分母，避免混在一个高分里。

评分器先以人为构造的正例、缺结果、错误数值、编造引用、状态没有变化、历史缺失等负例验收，确认不会把空结果或自称成功判过。答复人工判定是宿主审查，未做独立盲审；不得包装为专家科研评审。

## 避免把平台喂到成功

development / contrast 根据场景编号在运行前固定；contrast只作为不同表达/情境对照。**设计者见过所有题，因此不称为真正的未见集、盲测或泛化证明。** 完整首次基线保留，跑完前不按结果修改平台。后续修复必须保留本版基线，用新目录记录，不能改题、删失败或只汇报最佳一次。

当前一次运行不估计模型稳定性。真实新用户的自主操作、长周期科研和开放仓库复现仍未测。后续可邀请未看过项目的人走这些目标，另收真实表达，再做真正隔离的未见场景。

## 研究借鉴（没有移植榜单或背书）

- [τ-bench 评分协议](https://github.com/sierra-research/tau2-bench/blob/main/docs/evaluation.md)：结果状态和用户沟通分开核验，参考行动路径不应成为唯一可接受路径。本套不复制客服题目或套用其榜单分数。
- [ClarifyMT-Bench](https://arxiv.org/abs/2512.21120)：不完整信息、不同用户行为与多轮澄清的测评思路。未复现作者成绩。
- [InteractComp](https://arxiv.org/abs/2510.24668)：需要通过交互消除歧义的搜索问题。本套研究群目标和输出核验为自行设计。

这些文献帮助设计测量，不证明数据集已经代表所有新手用户。原始用户模拟、参考标准和模型输出保持分离，被测模型只收到生产平台本来会收到的消息与项目上下文，不接收本文件或评分答案。
