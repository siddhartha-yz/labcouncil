# 运行本地组会原型

这个版本已能走完：提交想法 → 后台三项任务 → 看报告和证据 → 追问 → 保存草稿 → 确认决定 → 下一轮继续。**角色和问答目前是固定程序模拟**，计算只支持两种 5 点合成数据，不能按任意 idea 自动科研。

## 开始使用

需要 Python 3.11 或更新版本。应用本身只有标准库依赖，不读取 `.env`，不用 API key，也不会产生模型费用。从仓库根目录执行：

```bash
python3 -m labcouncil start
```

然后打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。不要直接打开 HTML 文件。

`start` 在 Linux 上启动独立网页进程和 worker，重复运行会复用本实例。不会注册开机服务。每个实例使用独立运行目录；默认状态位于忽略的 `workspaces/labcouncil/`。

也可以各开一个终端，手动运行：

```bash
python3 -m labcouncil serve
python3 -m labcouncil worker
```

两个命令要使用同一个 `--database`。手动启动的进程用各自终端停止；`start/status/stop` 只管理带本实例标识的后台进程。

## 一次组会怎么用

1. 新建项目，填写想法；选择“平稳数据”。默认每轮执行资料、计算和复核三个模拟角色。
2. 等状态变成“已完成”，打开原始证据。网页不在场时 worker 也可以继续；一轮完成后等待你的决定。
3. 开始组会。报告会冻结在开会时；尚未完成的任务会明确显示，之后完成的产物仍在项目最新进度里。
4. 保存追问。当前答复是引用快照的模板，不是模型对任意问题的回答，讨论也不派单。
5. 编辑下一轮方向和输入。可以先“保存草稿，不派单”，之后重新打开。只有“确认决定”才发布下一轮计划；重复确认同一决定不再生成任务。

自由文字方向会保存为指令；模拟程序只执行你选择的数据场景，不能自动实现文字描述的新实验。每轮保存三份证据和内容哈希。复核角色从原始输入用另一种公式复算；这是算术检查，不是科研效果评估。

## 预算、暂停与定时材料

后台任务和组会答复分别计数。执行一个角色消耗 1 个模拟任务单位，保存一次答复消耗 1 个模拟问答单位。达到上限就停止启动对应操作；可在项目设置中调整总上限。**这些单位不是 API token、人民币或 GPU 时间。**

暂停阻止新任务启动；已经开始的短任务仍可保存结果。设置组会时间使用浏览器本机时区，后台按 UTC 时间戳判断，到时生成固定快照。若服务离线，重新启动后补准备过期的材料；不会代你确认决定。本版只有平台内待审状态，尚无外部提醒或循环周历。

```bash
python3 -m labcouncil status
python3 -m labcouncil stop
```

停止保留数据库，重启读回任务、证据、组会、草稿和决定。过期租约可重算固定模拟任务，旧 worker 的写入被拒绝；每个任务最多提交一份产物。崩溃可能导致模拟计算被执行两次，不能把“一个提交结果”当成“外部实验绝不重复”。真正外部工具仍需稳定运行 ID 和独立恢复适配。

## 验证与限制

```bash
python3 -m unittest discover -s tests -v
node --check labcouncil/static/app.js
```

HTTP 和生命周期测试需要允许本机回环通信；所有应用测试都不调用模型。实际网页验收记录见 [M1 记录](../reproductions/2026-10-06-m1-prototype/REPORT.md)。

本版限于个人本机使用：绑定 `127.0.0.1`，检查 Host、Origin 和 JSON 请求来源，静态文件按明确清单提供。尚无公网身份认证、数据库迁移体系、外部进程监督或长周期稳定性验收。真实模型、检索、隔离执行和真实费用预算属于 M2；上游候选的采用状态单独保存在持续工作清单。
