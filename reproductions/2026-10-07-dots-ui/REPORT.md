# Dots 设计适配的本地界面验收

日期：2026-10-07。参考与适配范围见[设计记录](../../docs/DOTS-DESIGN.md)。

## 方法

在独立忽略目录 `workspaces/dots-ui-acceptance` 创建程序演示项目，用实际浏览器与本机 HTTP API 验收。测试服务在处理聊天前人为延迟5秒，用于检查等待反馈；拒绝任何非 simulation 项目。没有调用真实模型或公开来源，也不改变用户研究项目的权限与额度。

该人为延迟不是模型耗时测量。当前程序演示只有五个固定数据点，结果验证交互和记录流程，不能评价科研水平。

## 已完成检查

- 在消息框发送 idea 建立项目；模型与工具权限初始关闭。
- 输入“允许本地计算”，活动页出现待讨论安排，确认前权限不生效。
- 输入“按这个做”，已有输入和讨论保留，任务排队；手动运行模拟 worker 得到输入、计算、独立复算三份报告。
- 专业角色在聊天中汇报，活动页展示三个完成步骤，并保留先前未执行步骤。
- 再补充资源和要求、同意后继续第二次模拟计算，之后继续两次提问，最终保留两次工作的六份报告、六条群聊消息与三版输入。任务已用6/9，模型及公开请求均为0。
- 点击计算活动打开保存的结果与原始证据入口。
- 资料页暂停和恢复可用，没有增加额度或改变权限。
- 发送后立即出现等待服务确认的消息，发送按钮在处理期间禁止重复提交；完成后恢复输入。
- 下一条答复仍在等待时，前一条问题继续可见，六张报告卡仍在；切换群聊后未发送草稿保留。
- 桌面宽度1280与窄屏布局分别检查；桌面聊天和活动并排，窄屏资料抽屉与研究群列表关闭后可回到聊天。
- 明确资源和要求在未授权模型调用时可记入待讨论安排；单元验证其不启动工作、不自行改变权限或费用上限。

用户现有研究项目的只读界面检查确认：过往超时失败、完成报告和未执行步骤均可区分；答复依据与实际调用耗时入口保留。个人研究输入、截图和运行状态仅留本机，不纳入此公开记录。

## 自动检查

平台单元与本机 HTTP 测试、JavaScript 语法和 diff 检查均运行；最终数量以本次提交验证结果为准。本次新增资源补充回归检查，不新增镜像 CSS 的测试。

平台110项测试通过。浏览器检查中发现发送等待画面一度使用旧页面闭包的数据，修复为使用最新项目快照，保存记录未受影响。手动观察已领取的模拟步骤超过30秒租约，旧owner保存被拒绝，随后模拟 worker 安全重算一次；该事件保留。真实后端的中断不采用这种自动重算。

尚未验证：真实模型下的新增端到端研究效果、长时间多人会话、完整 Dots 功能等价性、任意仓库复现、云电脑与第三方应用连接。
