# InternAgentS 最小运行验收

2026-10-06，源码固定为 `4a5f2ab2879ebd4f806155c796e247da94bb1625`。

本轮先试原版启动脚本、真实模型、工具审批与服务重启，不执行论文中的科研任务。隔离环境 Python 3.12.14；按上游 pyproject 安装依赖，UI 按 package-lock 安装。记录实际解析版本，不假定与作者运行环境一致。

小任务数据：x=0,1,2,3,4；y=1,3,5,7,9。要求真实读取 CSV、计算线性预测 2x+1 和常数均值预测的 MSE，写结果和简短中文报告。主机独立重算验收值应分别为 0 和 8。

验收步骤：启动三个原服务；提交任务；工具待审批时保存状态，重新读取并重启服务，再查询待审批状态和线程；确认后继续执行，检验实际文件；结束后重启查询会话及产物。若启动或 API 不兼容，保留原失败，不用替代实现冒充原版成功。

模型只使用已配置的 DeepSeek Flash。真实 key 只在本地代理进程中，框架拿到的是无效占位值。代理固定上游地址、限制最多 12 次转发、单次输出上限 1024 token、请求体上限 60000 字节、单次超时 90 秒；关闭 thinking，保留这个条件变化。代理限制是本次试验保护，不算上游已经实现的预算管理。先尝试普通任务，必要时再用小目标测试预算展示与自动续跑。

不配置外部 tracing/MCP/SCP/SSH/skills。原源码保持不变，配置通过上游支持的环境变量覆盖，项目限制在独立试验目录。记录 API 次数、用量、错误、审批决定、重启前后状态和文件哈希。程序化审批只代表测试操作者批准指定计算，不算用户真实组会。
